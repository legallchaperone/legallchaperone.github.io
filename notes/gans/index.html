1. Random variable & push-forward #

X:(Ω,F,μ)→(S,B),(X#μ)(B):=μ(X−1(B)) \mathsf{X} : (\Omega, \mathcal{F}, \mu) \to (\mathbb{S}, \mathcal{B}), \qquad (\mathsf{X}_\#\mu)(B) := \mu(\mathsf{X}^{-1}(B)) X:(Ω,F,μ)→(S,B),(X#​μ)(B):=μ(X−1(B))
  • X\mathsf{X}X is a deterministic function; randomness lives in μ\muμ.
  • Measurability: X−1(B)⊆F\mathsf{X}^{-1}(\mathcal{B}) \subseteq \mathcal{F}X−1(B)⊆F.
  • Measures pushed forward, sets pulled back.
  • Many ω\omegaω → one value ⇒ mass adds up.
  • Ω\OmegaΩ = shared source of randomness (gives joints, independence).
  • S\mathbb{S}S = observed values.
  • "X≃N(0,1)\mathsf{X}\simeq\mathcal{N}(0,1)X≃N(0,1)" means X#μ=N(0,1)\mathsf{X}_\#\mu = \mathcal{N}(0,1)X#​μ=N(0,1).

3. Theorem: representation through push-forward #

PPP continuous on Rm\mathbb{R}^mRm, QQQ any distribution on Rd\mathbb{R}^dRd ⇒ ∃f:Rm→Rd\exists f : \mathbb{R}^m\to\mathbb{R}^d∃f:Rm→Rd with f#P=Qf_\#P = Qf#​P=Q.

  • False if PPP has a delta mass (maps cannot split a point).
  • W.l.o.g. PPP = standard Gaussian.
  • fff not unique.
  • fff weird if m≪dm \ll dm≪d (non-Lipschitz).
  • Practice: only empirical Q^\hat QQ^​.

7. JS divergence #

Support:

  • Forward KL blows up where q>0q > 0q>0, pθ≈0p_\theta \approx 0pθ​≈0 ⇒ mode covering.
  • Reverse KL blows up where pθ>0p_\theta > 0pθ​>0, q≈0q \approx 0q≈0 ⇒ mode seeking.

L1 vs. L2 penalty per pixel.

Why L1:

  • L1 optimum = median (sharp); L2 optimum = mean (blur).
  • Robust to a few large errors.
  • Keeps pushing small errors to 0.

Failure: steganography (hide info in invisible noise).
